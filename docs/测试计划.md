# 测试计划 · 滚轮 & 切模

每次改动滚轮或切模后都要跑一遍。自动部分用 `tests/` 里的脚本，手动部分需要真机打印。

## 怎么跑

```bash
python3 build.py                       # 先生成 index.html
mkdir -p /tmp/qa && cd /tmp/qa         # 截图会存在当前目录
python3 <repo>/tests/qa_roller_cutter.py        # 全部 25 个用例；只跑一部分：... R3 C4
python3 <repo>/tests/qa_ui.py                   # 界面交互 7 项
```

需要 Python 的 playwright 和 Chromium。测试图片在 `tests/images/`（都是原创或程序生成）。

## 每个用例都检查

| 检查 | 通过标准 |
| --- | --- |
| STL 封闭 | 坏边 = 0，没有 NaN |
| 贴平台 | 最低点 z = 0 |
| 尺寸 | STL 外形和界面上的数字一致（误差 < 0.2 mm） |
| 导出 | ZIP 里有 STL、规格卡、规格说明、设置文件；文件名带类别（滚轮 / 切模，英文 roller / cutter） |
| 设置文件 | `product` 是对的类别 |
| 页面错误 | 没有 JS 报错 |
| 预览 | 截图人工看：有没有接缝线、缺块、错位、裁掉半个图案 |

## 2026-10-30 这一轮的结果

- 25 个用例全部：STL 封闭（坏边 0）、贴平台、没有页面错误；7 项界面交互全部通过。
- 这一轮发现并修好的：
  - 滚轮拼接处有一条线（预览），阴文时 STL 里可能有细沟 → 图案按整像素拼接。
  - 无缝图案默认每圈 2 个时只铺 1 排、两端空 14.66 mm → 上传时自动选能整排铺满的个数（鳞纹自动变成 3 × 2）。
  - 切模没字没图时尺寸显示 0.00 和印章的文字 → 改成「—」。
- 预期内的提示（不是 bug）：阴文「福」、反色鳞纹、反色花朵都有「两笔靠太近」的提示，是图案本身的细节。
